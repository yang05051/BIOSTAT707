# BIOSTAT 707 Checkpoint 1

This checkpoint is self-contained in the repository's `checkpoint_1/` directory. Place the 4,000 PhysioNet set-A record files in `checkpoint_1/data/set-a/` and `Outcomes-a.txt` in `checkpoint_1/data/`. From the repository root, run `cd checkpoint_1 && pixi run --locked checkpoint1`; when already inside `checkpoint_1/`, run `pixi run --locked checkpoint1`. The command renders the Quarto report to `output/checkpoint1.html` and regenerates `output/set-a_long.csv` (one row per recorded value, with raw and cleaned values) and `output/set-a_wide.csv` (one row per ICU stay, with static descriptors, outcomes, 48-hour summaries, two 24-hour measurement counts, and missingness indicators). Raw and derived data are ignored by Git; the rendered HTML is the only tracked file under `output/`.
